# Changelog

## 0.4.0

`kingstack setup` prepares `~/.kingstack` and never writes a native home.
It also writes a wrapper at `~/.local/bin/kingstack` that execs this
checkout. `check --all --mode live` only requires native homes that
exist. `kingstack session close` and `session sweep` mark leftover
rows done. The inbox distiller drops one-prompt health probes.
Checkout discovery uses `KINGSTACK_ROOT`, walk-up, then Hassan's default
path. A personal profile skips the king-mode overlay. PreCompact and
SessionStart keep Headroom archive ids and re-inject the memory index.
`memory consolidate` and `memory harvest` write candidates only.
`kingstack handoff` writes a Codex packet. `kingstack session` lists the
private working-set index under `~/.kingstack/sessions`. Pointers only.
The pstack checkout defaults to the sibling `plugins` repo, not a
hardcoded home path. Session prompts drop secret-like lines. An empty
handoff packet no longer erases a stored packet path. Images are not
crushed.
CI runs unit tests and staged health. `kingstack effort` scans spawn
lines; inherit is fail. Copy `~/.kingstack` to move machines. Standing
docs, sweeps, and adapter notes match this checkout.
`activate --apply --approved-briefing` writes native homes. Claude
`settings.json` owns `statusLine` and `hooks`. The six dated Superpowers
plan files are gone. The design spec stays.

## 0.3.0

`owned-paths.json` is the only ownership list. `release --select`
retargets a private `current`. Apply and rollback run on a temp home and
keep keys kingstack does not own. Schedules take a lock. Releases include
`claude-check` and `kingstack-path`. Curated Claude banks are copied into
`~/.kingstack/memory`. `kingstack status` prints model, effort, context,
and subagent models. Standing instructions now say the best rules live
in the code, work delete-then-simplify-then-speed-then-automate, and
treat a repeated smell as a constraint to encode. Cursor guidance is
`rules/kingstack`, hooks use Cursor's schema, and only poteto-mode and
king-mode auto-invoke. Headroom is pinned for CCR of large tool text.
Images are not crushed. Native homes are still not linked.

## 0.2.0

Shared memory, a Codex bundle, a Cursor adapter, and private releases
that refuse native homes.

## 0.1.0

Adapter contract, portable routing, skill catalog, Claude hook parity.
